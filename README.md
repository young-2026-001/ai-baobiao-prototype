# AI助手编报原型

基于 HTML / CSS / JavaScript 的「AI 助手」智能编报原型（产品原型）。

## 项目结构

```
AI助手编报原型/
├── AI助手编报原型.html    # 主页面
├── js/
│   └── dashboard.js       # 页面逻辑
└── styles/
    └── dashboard.css      # 样式
```

## 使用说明

直接用浏览器打开 `AI助手编报原型.html` 即可预览。

## 技术栈

- 原生 HTML5 + CSS3 + JavaScript
- Remix Icon 图标库（CDN 引入）
